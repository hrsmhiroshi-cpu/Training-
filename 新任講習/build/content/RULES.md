# 本文執筆の規律

スライドのみで完結させる。ワークシート等の別冊は作らないので、**スライド本文だけで
説明が成立している**ことを条件とする。

## 1. 予測を書かない

こちらで結果を推測して断定しない。書けるのは、条文・公的資料・承認済みテキストに
書かれていることと、そこから直接導ける行動指示だけ。

| 書かない | 書く |
|---|---|
| 追跡は有形力に発展しやすい | 追跡の先で相手に触れれば有形力になる |
| 書面を預かれば相手の手続きを遅らせる | 被害届を受理するのは警察である |
| 当時は質にばらつきがあった | 1972年まで警備業務を規律する法律はなかった |
| 条文の多くは禁止を定めている | 第15条は特別な権限を与えるものではないと明記している |

「〜が一般的」「〜になりやすい」「〜すると考えられる」は使わない。

## 2. 物語を作らない

TTX のシナリオは訓練用に設定した**架空の場面**であり、実例ではない。
ケーススライドのソース欄には必ず「架空シナリオ」を含める。

実例を引く場合は公表された事案のみとし、出典を明記して「参考資料」と示す。
登場人物の心情や背景を膨らませない。場面は、判断に必要な事実だけで構成する。

## 3. 過度な比喩を使わない

比喩は理解の助けにならず、外国籍の受講者には特に伝わらない。動作・条文・
役割で書く。

| 使わない | 使う |
|---|---|
| クライアントの「顔」として見られる | 来訪者が最初に接するのは警備員である |
| その土台の上に | 続いて |
| 最後の砦 | （書かない。役割を具体的に書く） |
| 生命線 | （書かない。何が起きるかを書く） |

## 4. 出典のないことは書かない

法令は条文番号、判例は年月日を明記する。裏の取れない事項は本文に出さず、
`[要確認]` を付すか Site SOP に委ねる。

数値・固有名詞・年号は、承認済みテキストか公的資料から直接引く。

## 5. 1行の長さ

日本語は概ね40字、英語は折り返して2行までに収める。英語は補助ではなく、
単独で読める本文として書く。
