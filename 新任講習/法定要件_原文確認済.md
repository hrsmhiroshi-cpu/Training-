## 第38条第2項 — 基本教育の教育事項

> 基本教育は、次の表の上欄に掲げる警備員（…）の区分に応じ、警備業務に関する
> 基本的な知識及び技能に係る同表の下欄に掲げる教育事項について行う教育とする。

### 一 新たに警備業務に従事させようとする警備員（＝新任）

| | 教育事項（原文） |
|---|---|
| イ | 警備業務実施の基本原則に関すること。 |
| ロ | **警備員の資質の向上に関すること。** |
| ハ | 警備業法その他警備業務の適正な実施に必要な法令に関すること。 |
| ニ | 事故の発生時における警察機関への連絡その他応急の措置に関すること。 |
| ホ | **護身用具の使用方法その他の護身の方法に関すること。** |

### 二 現に警備業務に従事させている警備員（＝現任）

イ 基本原則／ロ 法令／ハ 事故の発生時における〜応急の措置　の3事項。
新任の ロ（資質の向上）と ホ（護身）は現任にはない。

### 備考（教育の方法）

- 一 基本教育は、**指導教育責任者**又は同等の知識経験がある者として国家公安
  委員会が定める者が行う。
- 二 **一の項ニ及びホ**（＝新任の応急措置・護身）並びに二の項ハについては、
  **講義の方法及び実技訓練の方法による**。
  一の項ロ（資質の向上）は、講義の方法**又は**実技訓練の方法。
  その他は講義の方法による。
- 三 講義の方法は教本・視聴覚教材等を用いる方法（電気通信回線を使用するもの
  を含む）。

## 第38条第3項 — 業務別教育の教育事項

### 法第2条第1項第1号の警備業務（機械警備業務を除く）＝ 施設警備

| | 教育事項（原文） |
|---|---|
| イ | **警備業務対象施設における人又は車両等の出入の管理の方法に関すること。** |
| ロ | 巡回の方法に関すること。 |
| ハ | 警報装置その他当該警備業務を実施するために使用する機器の使用方法に関すること。 |
| ニ | **不審者又は不審な物件を発見した場合にとるべき措置に関すること。** |
| ホ | その他当該警備業務を適正に実施するため必要な知識及び技能に関すること。 |

> **「警備業務対象施設の構造・設備その他保安上の急所に関すること」という
> 教育事項は存在しない。** 構成案v3〜v5で二次出典から拾っていたものは誤り。
> 該当内容は ロ（巡回の方法）と ホ（その他必要な知識及び技能）に収まる。

### 備考（教育の方法）

- **業務別教育は、講義の方法及び実技訓練の方法により**、警備業務の区分ごとに、
  当該区分に係る指導教育責任者又は同等の知識経験がある者が行う。
- 一定の要件を満たす警備員については、**業務別教育の時間数を2で除した時間数
  又は5時間のいずれか少ない時間数**を上限として、実地教育の方法によることが
  できる（1号警備の場合）。

## 第38条第4項 — 新任教育の時間数

> 新たに警備業務に従事させようとする警備員（…）に対する教育は、（…）
> 同表の下欄に掲げる教育時間数以上行うものとする。

| 警備員の区分 | 教育の種類 | 時間数 |
|---|---|---|
| **一　二の項から七の項までに掲げる警備員以外の警備員** | **基本教育及び業務別教育** | **20時間** |
| 二　合格証明書等の交付を受けている者で他種別に従事させようとするもの | 業務別教育 | 10時間 |
| 三　同上のうち、最近3年間に当該業務に通算1年以上従事したもの | 業務別教育 | 3時間 |
| 六　最近3年間に当該区分の業務に通算1年以上従事した警備員 | 基本教育及び業務別教育 | 7時間 |
| 七　最近3年間に他区分の業務に通算1年以上従事した警備員、警察官の職に通算1年以上あった警備員 | 基本教育及び業務別教育 | 13時間 |

→ 一般の新任は **20時間**。基本教育と業務別教育の内訳は規定されておらず、
各社の裁量である。

## 第38条第5項 — 現任教育の時間数

一般の警備員は **毎年度 基本教育及び業務別教育 10時間**。
前回現任講習が10時限であったことと一致する。

備考: 新任として基本教育／業務別教育を行った日の属する年度は、現任教育の
当該部分を行わなくてよい。

## 本講習への反映

### 時間数

Day 1（基本教育 7時限）＋ Day 2（業務別教育 8時限）＋ Day 3（6時限）= **21時限**。
第38条第4項一の項の20時間（以上）を満たす。

Day 2 は第15時限を加えたため 8:00 – 17:25。Day 1 は 8:00 – 16:20 のまま。

### 科目の割付（確認済の原文で表記）

| 時限 | 区分 | 法定科目 |
|---|---|---|
| 1 | 基本教育1 | イ 警備業務実施の基本原則 |
| 2 | 基本教育2 | ロ 警備員の資質の向上に関すること |
| 3 | 基本教育3 | ハ 警備業法その他〜必要な法令 ① |
| 4 | 基本教育4 | ハ 同 ② |
| 5 | 基本教育5 | ニ 事故の発生時における警察機関への連絡その他応急の措置 ① |
| 6 | 基本教育6 | ニ 同 ②（**実技**） |
| 7 | 基本教育7 | ホ 護身用具の使用方法その他の護身の方法（**実技**） |
| 8 | 業務別教育1 | ホ その他当該警備業務を適正に実施するため必要な知識及び技能 |
| 9 | 業務別教育2 | ホ 同 |
| 10 | 業務別教育3 | ホ 同 |
| 11 | 業務別教育4 | イ 警備業務対象施設における人又は車両等の出入の管理の方法 |
| 12 | 業務別教育5 | ロ 巡回の方法に関すること |
| 13 | 業務別教育6 | ニ 不審者又は不審な物件を発見した場合にとるべき措置 |
| 14 | 業務別教育7 | ハ 警報装置その他〜機器の使用方法（消防用設備） |
| 15 | 業務別教育8 | ハ 同（警備用機器：カメラ・入退室管理・無線・非常通報装置） |

業務別教育の5事項（イ〜ホ）はすべて Day 2 で扱っている。

科目ハは第14・15時限の2コマに分けた。第14時限は消防用設備（消火器・屋内消火栓・
自動火災報知設備）、第15時限は警備員が日常操作する警備用機器（防犯カメラ、入退室
管理システム、業務用無線機、非常通報装置、機械警備の受信機）である。条文が言う
「当該警備業務を実施するために使用する機器」は後者に当たるため、第15時限を加えた。

### 実技訓練の要件

備考二により、**ニ（応急措置）と ホ（護身）は講義及び実技訓練の両方**が必要。

- 第5時限　講義＋通報訓練（実技）
- 第6時限　実技（胸骨圧迫・AED）
- 第7時限　**実技を追加**（距離・姿勢・声、離脱。2人1組で交代）

業務別教育も備考により講義及び実技訓練による。Day 2 の各コマは TTX の
グループ討議と発表を実技訓練として実施する。

### 実施者の要件

基本教育・業務別教育とも、**指導教育責任者**または国家公安委員会が定める
同等の知識経験がある者が行う。
