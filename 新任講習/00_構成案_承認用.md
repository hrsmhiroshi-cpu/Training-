## 1. 先にお伝えする制約 — 画像と参考HPについて

当環境のプロキシは外部サイトを全面遮断しています。消防関係も確認済みで全滅でした。

```
https://www.fdma.go.jp/            → 000 (遮断)
https://www.jfema.or.jp/           → 000 (遮断)
https://www.tfd.metro.tokyo.lg.jp/ → 000 (遮断)
```

したがって **Webから画像を直接取得すること、参考HPのURL到達確認はできません**。

ただし **参考HPのURLをスライドに記載すること自体は問題ありません**（到達確認ができないだけ）。また画像も、以下の3経路のうち2つは今すぐ使えます。

### 画像の3経路

| 経路 | 可否 | 内容 |
|---|---|---|
| **A. 作図** | **○ 今すぐ可** | 構造図・手順図はこちらでベクター作図します。和英併記ラベルを付けられ、不要な情報が写り込まないため、**教材としてはむしろ写真より適します** |
| **B. Drive経由** | **○ 検証済み** | HRSMがDriveに画像を置けば、こちらで取り出してpptxに埋め込めます。**検証実施: `Vector Logo2.png` を取得し、有効なPNG（1346×1256 RGBA、54,800バイト）としてデコード成功** |
| **C. Web直接取得** | **× 不可** | 現環境では遮断。ネットワークポリシーを変更した環境なら可能（下記） |

### ネットワーク環境を変えれば取得できるか → できます。ただし推奨しません

遮断しているのは**この実行環境のネットワークポリシー**（egress proxy）で、資料形式やこちらの能力の制約ではありません。Claude Code on the web の環境作成時に選択する設定なので、ポリシーを緩めた環境や、ドメイン許可リストに消防庁等を追加した環境であれば取得できます。
参照: https://code.claude.com/docs/en/claude-code-on-the-web

**ただし、ネットワークが開いても Web 画像の使用は推奨しません。**

- Webで見つかる消火器写真には**著作権**があります
- 消防庁・自治体サイトの画像も、多くは転載条件が付きます
- 本資料は受講者に配布する教材であり、社内利用でも**権利処理が必要**です

→ **ネットワーク制約の有無にかかわらず、「配属先または自社施設で撮影した実機写真」が最善**という結論は変わりません。権利面が安全で、かつ受講者が実際に目にする設備と一致するため教育効果も高く、そのままSite SOPの補助教材にもなります。

### 撮影は行わない（HRSM決定）

現場撮影は実施しない方針で確定しました。**すべて作図で対応します。**

| 対象 | 対応 |
|---|---|
| 消火器・屋内消火栓 | 指定HPへのリンク＋QRコード（画像は飛んで確認） |
| 自動火災報知設備の系統図・感知器の種類・誘導灯・防火戸・防煙垂れ壁 | **自作作図** |
| AED（第6限 実技） | **自作作図**（AED収納ボックスと操作手順の模式図） |

写真がなくても成立する設計にします。

### 6-3. 警備員としての線引き（この設備コマの主眼）

設備の知識そのものより、**どこまでやるかの線引き**を軸に据えます。前回現任第10限の「機器は異常を知らせる。判断は人が行う」を新任向けに具体化します。

- 消火器による初期消火は、**炎が天井に達する前まで**が目安。それ以降は避難と通報を優先する
- **背中を出口側に置く**。消火のために奥へ入らない
- 操作方法を知らない設備には触れない
- 音を止めることは目的ではない
- 発報＝火災確定ではない。地区表示を読み、確認前に「火事です」と言わない
- 消防隊到着後は指揮下に入る。誘導と情報提供に徹する

## 9. 作成ルール（前回現任講習準拠）

1. 1時限=1ファイル。`NN_N限_主題.pptx`
2. 表紙 =「第N時限 HH:MM–HH:MM／基本教育N（業務別教育N）／法定科目名／和英併記／実施日・講習種別」
3. フッター =`第N時限｜基本教育N 法定科目名 / Period N | …`＋ページ番号
4. **全ページ和英併記**（日本語1行の直後に英語1行）
5. 各セクション冒頭に「**身につくこと / What You'll Learn**」＋ブロック記号
6. 内容スライドは**4ブロック×各4項目**
7. 内容スライド末尾に「**Site SOP優先**」ボックス
8. スライド末尾に「**ソース**」（法令名・公的資料名）
9. TTX = シナリオ／問い4問／**追加付与①②**／統一の問い「**あなたなら次の60秒、何をどう動きますか**」
10. 模範解答は別スライド（DEBRIEF）＋注記
11. 各時限末に「まとめ」＋次時限への橋渡し1行
12. Day 1・Day 2 の最終時限に AAR ＋確認テスト10問＋解答解説
13. トーン：説教調・煽り禁止／結論でなく根拠／「使命」連呼禁止／クライアント特定表現なし
14. 法令は条文番号明記、判例は年月日明記、未確認は `[要確認]`
15. **公開実例は「参考資料」として出典明記のうえ記載する**
