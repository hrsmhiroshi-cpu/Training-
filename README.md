## スライドの構成

社内既存資料（`VRM_NewHire_CorpSec_4h`）の形式に合わせています。

- **身につくこと / What You'll Learn** ― 各スライド冒頭の学習目標
- **番号付きトピック4個 × 3〜4ブレット** ― 日本語の下に英語
- **Site SOP優先** ― 現場ごとに異なる事項を明示
- **ソース** ― 根拠法令・出典

演習スライドは **シナリオ → 問い（60秒）→ 検討の観点4つ → 追加付与** の形式です。

## 全コマ共通の3つの問い

1. **何を守っているのか。** ― People / Asset / Reputation のどれか（情報は Asset に含む）
2. **どの立場で動くのか。** ―「私人」か「管理権者の補助者」か
3. **その手段は最小限か。** ― 越えた場合、何の罪に当たるか

## 外国人隊員への対応

| 箇所 | 内容 |
|---|---|
| 第5時限 冒頭 | **警察官と警備員の権限の違い**（警職法の各権限を並べ、警備員にはいずれもないことを示す） |
| 第5時限 | **日本の法律用語**8語。漢字＋ローマ字＋英語＋注意点 |
| 第9時限 | **通報で使う日本語**8文。漢字＋ローマ字＋英語。全員が言えることを求める |
| 全編 | 英文は短文・非慣用句。重要語はローマ字を併記 |
| 講師用カード・テスト・ワークシート | 混成班の編成、英語での回答可 |

他国の法制度については具体的な断定をしていません（正確性を担保できないため）。

## ロゴ

全スライドの右上、同一位置にロゴを1点ずつ挿入しています。**色・アスペクト比は無加工**です。
スライドの配色もロゴの実測色（ネイビー `#093259` / ティール `#12B198`）に統一しています。

```bash
python3 build/prep_logo.py    # assets/ の原本から logo.png と meta を生成
node build/generate.js        # decks/ に6ファイルを出力
```

## 資料の再生成

```bash
npm install pptxgenjs      # 初回のみ
node build/generate.js
```

| ファイル | 役割 |
|---|---|
| `build/design.js` | 配色・余白・ロゴ枠・日英併記のヘルパー |
| `build/layouts.js` | スライドの型（表紙／トピック／演習／比較／リスト／まとめ） |
| `build/content-a.js` | 第1・2時限の原稿（移管済み） |
| `build/content-b.js` | 第4・5時限の原稿 |
| `build/content-c.js` | 第9・10時限の原稿 |
| `build/generate.js` | 出力 |

文言の修正は `content-*.js` を編集して再生成してください。レイアウトには手を入れずに済みます。
