## ロゴの差し込み

全61枚に、右上の同一位置へロゴを1点ずつ挿入します。**色・アスペクト比は無加工**です。

```bash
# 1. 原本を置く（.tif / .tiff / .png / .jpg のいずれか）
#    assets/logo.tif
# 2. 変換とメタ生成
python3 build/prep_logo.py
# 3. 全デッキを再生成
node build/generate.js
```

TIFFはPowerPoint・Google Slidesで表示が不安定なため、**可逆でPNGに変換**してから埋め込みます。
ピクセルはそのまま複製するので、色も縦横比も変わりません。
ただし**原本がCMYKの場合のみ**、RGB変換で色がわずかに動きます（原理上、完全一致は不可能）。
`prep_logo.py` が該当を検出して警告します。

ロゴ未配置のままでも生成は通り、その領域は空欄のまま出力されます。

## 資料の再生成

```bash
npm install pptxgenjs      # 初回のみ
node build/generate.js     # decks/ に6ファイルを出力
```

| ファイル | 役割 |
|---|---|
| `build/design.js` | 配色・余白・ロゴ枠・日英併記のヘルパー |
| `build/layouts.js` | スライドの型（表紙／リスト／カード／条文／比較／演習／まとめ） |
| `build/content-a.js` | 第1・2時限の原稿 |
| `build/content-b.js` | 第4・5時限の原稿 |
| `build/content-c.js` | 第9・10時限の原稿 |
| `build/generate.js` | 出力 |

文言の修正は `content-*.js` を編集して再生成してください。レイアウトには手を入れずに済みます。
