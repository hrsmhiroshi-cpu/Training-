# TTX Scenario Cards — Facilitator Copy

**実施日 / Date**：2026年8月11日（火）
**担当 / Instructor**：第1・2・4・5・9・10時限
**班編成 / Groups**：20名前後 → 4班（各5名）／ 4 groups of 5

> **進行の原則 / Facilitator rules**
> ・正解を先に示さない。班に述べさせる。 / Do not give the answer first. Have the group state it.
> ・結論ではなく根拠を評価する。 / Assess the reasoning, not the conclusion.
> ・意見が分かれた場合は、分かれた理由を発表させる。 / If the group splits, have them present why.
> ・第2インジェクトは、班が結論を出した直後に口頭で投入する。 / Deliver the second inject verbally, right after they settle.

# TTX ① 社内の持ち出しを現認した ＜第2時限＞

**状況** 20時。退社しようとする従業員のバッグから、会社備品のノートPCが見えている。声をかけると「部長の許可は取ってある」と言い、立ち止まらない。持ち出し許可証の運用は先月変更されたばかりで、あなたは新しい様式を見たことがない。

**インジェクト①（スライド表示）** 相手はそのまま出口へ向かった。追うか、追わないか。

**インジェクト②（口頭・討議中に投入）**
> 無線が入る。「こちら警備長。出口で止めろ。行かせるな。」

### 講評ポイント

| 論点 | 押さえるべきこと |
|---|---|
| 犯罪か、確認事項か | 従業員が会社備品を持つこと自体は犯罪ではない。権利の所在が不明確で、現行犯逮捕の明白性は満たしにくい |
| 情報の欠落 | 許可証の様式を知らない。**知らないことを判断の根拠にしない**。確認できる者に確認する |
| 私人か補助者か | 補助者の場面。確認の依頼、記録、報告はできる。強制はできない |
| 追跡 | 追跡しない判断も成り立つ。有形力に発展する可能性と、信用への影響を考慮する |
| **インジェクト②** | **上位者の指示でも、警備員の権限は増えない。**「止めろ」を物理的な制止と解すれば実行できない |
| 指示への対応 | 断り方が論点。「実力での制止はできません。記録と報告を行います」と代替案を返す。無言で従わないのが最も悪い |
| 記録 | 時刻、品目、型番、会話内容。**上位者の指示内容と、それにどう応答したかも記録する** |
| 結論 | 警備が結論を出さない。人事・法務へ引き継ぐ |

**割れる論点** 指示に従うか否か。従うと答えた班には「何をもって止めるのか」を問う。

# TTX ② 巡回中、この場面に出会ったら ＜第4時限＞

**進め方** 6場面から班で3つ選ぶ → 4つの問いに回答 → 発表。**各場面は情報が不足している。**

| # | 場面 | 主リスク | 論点 |
|---|---|---|---|
| A | 無人の席にIDカード。離席中か不明 | Asset（情報） | 拾って預かるか、その場に残して報告か。**触れた場合は記録する** |
| B | ホワイトボードに案件名と金額。会議は終了 | Asset（情報） | 消してよいか。消す前に記録が必要な場合がある |
| C | 非常口前に段ボール3箱。搬入作業が継続中 | People | 避難障害。**作業中であることが判断を難しくする**。作業者への声かけが必要 |
| D | サーバ室の扉が半開き。中は見えない | Asset（情報） | 人がいる可能性。**単独で入らない** |
| E | バッジ未着用者が「役員だ」と名乗る | People / Asset | 断定しない。手続きに戻す（第5時限に接続） |
| F | 外周フェンス破損。前回巡回時の記憶が不確か | Asset（物的） | **不確かであることを報告に書けるか**。写真と時刻を残す |

### 4つの問い
1. 何に注意するか（People / Asset / Reputation のどれか）
2. どこを見るか
3. どう巡回するか（次の巡回で何を変えるか）
4. どう報告するか（報告するか、誰に、何を。事実と評価を分けて）

### 講評ポイント
- リスクを People / Asset / Reputation で区別できたか
- 「その場の処置」と「報告」を分けたか
- **情報が不足していることを、報告に書いたか**（F、A が該当）
- ③の巡回設計の変更まで検討したか
- C は「作業中」という条件があるため、除去してよいかの判断が割れる

# TTX ③ この台詞のうち、どれを選ぶか ＜第5時限＞

**状況** 来訪者が「役員に呼ばれている、急いでいる」と述べ、入館手続きを拒んでいる。来訪予定表に同姓の記載はあるが、当該役員に電話がつながらない。声はやや大きく、周囲の来訪者が振り返っている。

### 提示する台詞

| | 台詞 | 評価 |
|---|---|---|
| **A** | 「規則ですので通せません」 | 拒否のみ。引き下がれる形が残らない |
| **B** | 「お急ぎのところ恐れ入ります。すぐ確認いたしますので、こちらでお待ちいただけますか」 | 受け止めと手続きへの誘導、待つ場所の提示ができている |
| **C** | 「落ち着いてください」 | 相手の状態を否定している |
| **D** | 「どちらの役員でしょうか。お名前を伺えれば、こちらからお繋ぎします」 | 手続きに戻しつつ、相手に協力の余地を残している |

**B の後に D** が実務的。Bで受け止め、Dで具体化する。

**インジェクト①（スライド表示）** 相手がスマートフォンを向け、撮影を始めた。

**インジェクト②（口頭・討議中に投入）**
> 別の来訪者が横から「その対応はおかしいんじゃないの」と割って入る。

### 講評ポイント
- 選んだ台詞が、拒否ではなく手続きへの誘導になっているか
- 有形力（進路に立つ、腕に触れる）に頼っていないか
- 引き下がれる形を残し、選択肢を示したか
- **予定表の同姓は根拠にならない**。同姓の別人の可能性がある。断定しない
- **撮影されても対応を変えない**。変えるとすれば「変えた」こと自体が問題になる
- **インジェクト②** 第三者には応答しない。会社の見解を作らない。対応相手を増やさない
- 相手がゲートへ向かった場合は追わない。応援と通報に切り替える

# TTX ④ 執務フロアで人が倒れている ＜第9時限＞

**状況** 17時40分、執務フロアで人が1名倒れている。社員証も来訪者バッジも見当たらない。近くに割れたガラスと、開いたままのキャビネット。周囲の従業員3名は「見たことがない人だ」と言う。呼びかけても日本語が通じない。

**インジェクト①（スライド表示）** 別の従業員が「早く片付けよう」と、割れたガラスを拾い始めた。

**インジェクト②（口頭・討議中に投入）**
> 救急隊から「本人の名前と生年月日は分かりますか」と聞かれた。

### 講評ポイント

| 論点 | 押さえるべきこと |
|---|---|
| 最初の30秒 | ①周囲の安全 ②反応の確認 ③**人を指名して**119番と応援を依頼（「誰か」では動かない） |
| 110か119か | まず119。人命が先。事件性の判断は後からできる |
| 両方か | ガラスとキャビネットは事件性を示す。119の後に110、または社内から並行して |
| **所持品確認** | **ここが最大の論点。** 所持品検査は同意が要件だが、相手に意識がなく同意を得られない |
| | 救護のための身元確認と、所持品検査は目的が異なる。**救急隊・警察の到着後に、その面前で行うのが安全**。単独で財布を開けない |
| | 実施した場合は、**誰の面前で、何を、何時に確認したか**を必ず記録する |
| 言語 | 日本語が通じないことを**119番通報時に伝える**。通訳対応につながる |
| インジェクト① | 止める。「そのままにしてください」と理由を添える。善意の行動なので、責める言い方をしない |
| インジェクト② | 分からないものは「分かりません」と答える。**推測で答えない** |
| エスカレーション | 一次＝警備責任者へ即時。人身事故のため三次（経営層・広報・法務）まで想定する |

**割れる論点** 所持品を見てよいか。「見てよい」と答えた班には根拠を、「見ない」と答えた班には救急隊への対応をそれぞれ問う。

# TTX ⑤ 総合演習 ＜第10時限＞

**状況** 18時40分、受信機が3階東区画で発報。ほぼ同時刻、入退室ログに、退職者に返却済みのはずのカードによる3階の解錠記録。防火戸が閉鎖。管理権者は不在で電話がつながらない。勤務中の警備員は、あなたを含めて2名。

**インジェクト①（スライド表示）** 3階の従業員から「煙は見えない」と無線が入った。判断を変えるか。

**インジェクト②（口頭・討議中に投入）**
> 受信機が、4階西区画で第2報を表示した。

### 講評ポイント

| 論点 | 押さえるべきこと |
|---|---|
| 最初の60秒 | 地区表示を読む → 一報を入れる → 現場確認に向かう。**動く前に一報** |
| 2名の配置 | **単独で現場確認に行かない**ことと、**受信機を無人にしない**ことが両立しない。どちらを取るかを説明できるか |
| 通報 | 発報＝火災の確定ではない。現場確認前に119するかは社内基準による |
| インジェクト① | 「煙が見えない」は火災を否定する根拠にならない。感知器の位置と煙の性質が異なる。**判断を変えない** |
| インジェクト② | 2区画同時発報は、非火災報より火災の可能性が上がる。**ここで通報判断を切り替えられるか** |
| ログ・画像 | 退職者カードの解錠記録は保全対象。上書き前に依頼する。**気づけた班を評価する** |
| **管理権者不在** | 保全を誰に依頼するか。緊急連絡体制の次順位者へ。**不在を理由に何もしないのが最も悪い** |
| 後回しにするもの | 不正解錠の追跡は後回しになる。**捨てる判断とその根拠を言えるか** |
| 現場保存 | 火災対応と証拠保全が競合する。人命 → 消火 → 保全の順 |

**この演習の狙い** 2つの事象が重なっており、人員が足りない。**全部はできない。**
何を捨てたか、その根拠を説明できるかを見る。

## AAR ― 演習後の振り返り（第10時限）
## After Action Review

**原則：犯人探しをしない。** / Rule: no blame.

1. 何が起きるはずだったか / What was supposed to happen?
2. 実際には何が起きたか / What actually happened?
3. なぜ差が生じたか / Why was there a difference?
4. 次に何を変えるか / What will we do differently?

**締め** 各自が明日から変える行動を1つ、声に出して述べる。
*Each participant states aloud one thing they will change from tomorrow.*
