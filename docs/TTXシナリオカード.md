> ・正解を先に示さない。班に述べさせる。

> ・意見が分かれた場合は、分かれた理由を発表させる。

# 第5時限　De-escalation

## TTX 5-A　入館手続きを拒む来訪者

**状況** 来訪者が「役員に呼ばれている、急いでいる」と述べ、入館手続きを拒む。来訪予定表に同姓の記載はあるが、当該役員に電話がつながらない。声はやや大きく、周囲の来訪者が振り返っている。

**提示する台詞**

| | 台詞 | 評価 |
|---|---|---|
| A | 「規則ですので通せません」 | 拒否のみ。引き下がれる形が残らない |
| B | 「すぐ確認いたしますので、こちらでお待ちいただけますか」 | 受け止めと手続きへの誘導、待つ場所の提示 |
| C | 「落ち着いてください」 | 相手の状態を否定している |
| D | 「どちらの役員でしょうか。お名前を伺えれば、お繋ぎします」 | 手続きに戻しつつ、協力の余地を残す |

**B の後に D** が実務的。Bで受け止め、Dで具体化する。

**インジェクト①（スライド）** 相手がスマートフォンを向け、撮影を始めた。
**インジェクト②（口頭）** 別の来訪者が横から「その対応はおかしいんじゃないの」と割って入る。

| 論点 | 押さえるべきこと |
|---|---|
| 同姓の記載 | **根拠にならない。** 同姓の別人がありうる。断定しない |
| 周囲の来訪者 | Reputation の問題。**声を下げるのはこちらから** |
| 撮影 | **対応を変えない。** 変えたこと自体が後で問題になる |
| インジェクト② | 第三者には応答しない。会社の見解を作らない。**対応相手を増やさない** |
| ゲートへ向かった場合 | 追わない。応援と通報に切り替える |
| 有形力 | 進路に立つのは境界。**説明できない立ちふさがりはしない** |

## TTX 5-B　退去に応じない元従業員

**状況** 17時、エントランス。3か月前に退職した元社員が「私物を取りに来た。上司とは話がついている」と述べ、ゲート前に座り込んでいる。人事は担当者不在。退勤する社員が足を止めて見ている。相手は落ち着いているが動く意思はない。

**インジェクト①（スライド）** 元社員が「不当解雇だ」と大きな声で話し始めた。
**インジェクト②（口頭）** 通りかかった社員の一人が「私が話しますよ」と間に入ろうとした。

| 論点 | 押さえるべきこと |
|---|---|
| 退去要請の根拠 | **管理権者の意思に基づく。** 自分の判断で命じるものではない |
| 有形力 | **使えない。** 座り込みに対して引き起こす、腕をつかむは暴行になりうる |
| 見ている社員 | People（安全）と Reputation（対応の質）が同時に問われる |
| 経緯への対応 | 退職理由に立ち入らない。**話を聞く相手にならない** |
| インジェクト① | 内容に応答しない。「お答えできる立場にありません」で足りる |
| インジェクト② | **止める。**善意でも当事者を増やすと収拾がつかない。社員の安全も守る対象 |
| 通報 | 退去要請が明確に拒否され、不退去が続いた時点。**その前に上長へ一報** |

**割れる論点** どの時点で通報するか。早すぎても遅すぎても問題になる。根拠を言わせる。

# 第9時限　通報と現場保存

## TTX 9-A　執務フロアで人が倒れている

**状況** 17時40分、執務フロアで人が1名倒れている。社員証も来訪者バッジも見当たらない。近くに割れたガラスと開いたままのキャビネット。周囲の社員3名は「見たことがない人だ」と言う。呼びかけても日本語が通じない。

**インジェクト①（スライド）** 別の社員が「早く片付けよう」と、割れたガラスを拾い始めた。
**インジェクト②（口頭）** 救急隊から「本人の名前と生年月日は分かりますか」と聞かれた。

| 論点 | 押さえるべきこと |
|---|---|
| 最初の30秒 | ①周囲の安全 ②反応の確認 ③**人を指名して**119番と応援を依頼。「誰か」では動かない |
| 110か119か | **まず119。** 人命が先。事件性の判断は後からできる |
| **所持品確認** | **最大の論点。** 検査は同意が要件だが、意識がなく同意を得られない |
| | 救護のための身元確認と、所持品検査は目的が異なる。**救急隊・警察の面前で行うのが安全**。単独で財布を開けない |
| | 実施した場合は、誰の面前で、何を、何時に確認したかを必ず記録する |
| 言語 | 日本語が通じないことを**119番通報時に伝える**。通訳対応につながる |
| インジェクト① | 止める。「そのままにしてください」と理由を添える。善意の行動なので責める言い方をしない |
| インジェクト② | 分からないものは「分かりません」。**推測で答えない** |
| エスカレーション | 一次＝警備責任者へ即時。人身事故のため三次（経営層・広報・法務）まで想定 |

**割れる論点** 所持品を見てよいか。「見てよい」派には根拠を、「見ない」派には救急隊への対応を問う。

## TTX 9-B　執務室から煙が出ている

**状況** 18時20分、5階の会議室から白い煙。扉は閉まっており中は見えない。自動火災報知設備はまだ発報していない。フロアに社員が20名ほど残っている。あなたは1名、応援は3分かかる。

**インジェクト①（スライド）** 社員の1人が「消火器を持ってくる」と言って走り出した。
**インジェクト②（口頭）** 発報した。同じ5階の別区画。

| 論点 | 押さえるべきこと |
|---|---|
| 扉を開けるか | **開けない。** 熱を確認する。開けると空気が入り燃焼が拡大する |
| 何で判断するか | 扉の熱、煙の色と量、臭気、音。目視できなくても判断材料はある |
| 初期消火か避難誘導か | **1名なら避難誘導。** 初期消火は複数名と退路の確保が前提 |
| 発報前の通報 | **してよい。** 発報を待つ理由はない。人が煙を確認している |
| 諦めるもの | 初期消火、原因の特定、私物の持ち出し |
| インジェクト① | **追わない。** 避難誘導を優先する。走り出した社員を止めに行くと誘導が止まる |
| インジェクト② | 2区画目の発報で火災の可能性が上がる。**全館避難の判断へ切り替える** |
| 通報内容 | 「火事です」を最初に。5階、進入口、在館者数、煙を確認していることを伝える |

# 第10時限　機器と総括

## TTX 10-A　総合演習

**状況** 18時40分、受信機が3階東区画で発報。ほぼ同時刻、入退室ログに、退職者に返却済みのはずのカードによる3階の解錠記録。防火戸が閉鎖。管理権者は不在で電話がつながらない。勤務中の警備員はあなたを含めて2名。

**インジェクト①（スライド）** 3階の社員から「煙は見えない」と無線が入った。判断を変えるか。
**インジェクト②（口頭）** 受信機が、4階西区画で第2報を表示した。

| 論点 | 押さえるべきこと |
|---|---|
| 最初の60秒 | 地区表示を読む → 一報を入れる → 現場確認。**動く前に一報** |
| 2名の配置 | **単独で確認に行かない**ことと**受信機を無人にしない**ことが両立しない。どちらを取るか説明できるか |
| インジェクト① | 「煙は見えない」は火災を否定する根拠にならない。感知器の位置と人の位置は違う。**判断を変えない** |
| インジェクト② | 2区画同時発報。非火災報の可能性が下がる。**通報判断を切り替えられるか** |
| ログ・画像 | 退職者カードの解錠記録は保全対象。上書き前に依頼。**気づけた班を評価する** |
| 管理権者不在 | 緊急連絡体制の次順位者へ。**不在を理由に何もしないのが最も悪い** |
| 後回しにするもの | 不正解錠の追跡。**捨てる判断とその根拠を言えるか** |

**狙い** 2つの事象が重なり、人員が足りない。**全部はできない。**何を捨てたかを問う。

## TTX 10-B　上司が入退室ログの提供を求める

**状況** 21時、クライアント企業の部長が防災センターに来る。「うちの部員が備品を持ち出した疑いがある。今日の入退室ログとエレベーターホールのカメラ画像を、いま見せてほしい」。相手は日頃から警備に協力的。上長は不在。

**インジェクト①（スライド）** 相手が「では、私が見るのではなく、あなたが見て教えてほしい」と述べた。
**インジェクト②（口頭）** 相手が「では正式に依頼書を出す。それまで消さないでくれ」と述べた。

| 論点 | 押さえるべきこと |
|---|---|
| 管理職であること | **開示の根拠にならない。** 開示の可否は契約とクライアントの規程で決まる |
| 警備員の権限 | **判断する立場にない。** 取り次ぐところまで |
| 断り方 | 「私には開示の判断ができません。担当へお繋ぎします」。**関係を壊さずに断れるか** |
| インジェクト① | **同じこと。** 自分が見て伝えるのは開示と同じ結果になる。応じられない |
| インジェクト② | **これは受けてよい。** 保全は上書きを防ぐ行為で、内容を渡す行為ではない |
| 保全と開示の違い | ここが本問の核。**保全＝残す／開示＝渡す。**警備員が受けられるのは前者だけ |
| 記録 | 求められた内容、断ったこと、その理由、保全を依頼された事実、時刻 |

**割れる論点** インジェクト①に気づけるか。「見せない」から「見て教える」への言い換えを見抜けるかが要点。

## AAR ― 演習後の振り返り（第10時限）

**原則：犯人探しをしない。**

1. 何が起きるはずだったか
2. 実際には何が起きたか
3. なぜ差が生じたか
4. 次に何を変えるか

**締め** 各自が明日から変える行動を1つ、声に出して述べる。
