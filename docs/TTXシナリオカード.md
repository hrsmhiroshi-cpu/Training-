# TTX シナリオカード（講師用）
# TTX Scenario Cards — Facilitator Copy

**実施日 / Date**：2026年8月11日（火）
**担当 / Instructor**：第1・2・4・5・9・10時限
**班編成 / Groups**：20名前後 → 4班（各5名）／ 4 groups of 5

> **講師の原則 / Facilitator principles**
> ・正解を先に言わない。班に言わせる。 / Never give the answer first — draw it out.
> ・結論ではなく根拠を評価する。 / Assess the reasoning, not the conclusion.
> ・意見が割れたら、割れた理由を発表させる。 / When a group splits, have them present *why*.
> ・追加付与（インジェクト）は、班が結論を出した直後に投入する。 / Deliver the inject the moment a group settles.

# TTX ① 社内の持ち出しを現認した ＜第2時限＞
# Witnessing an Internal Removal — Period 2

**状況** 20時。退社しようとする従業員のバッグから、会社備品のノートPCが見えている。持ち出し許可証はない。声をかけると「部長の許可は取ってある」と言い、立ち止まらない。

**Situation** 20:00. As an employee leaves, a company laptop is visible in their bag. There is no removal permit. When addressed, they say "I have the director's permission," and keep walking.

**追加付与 / Inject** 相手はそのまま出口へ向かった。追うか、追わないか。
*They head straight for the exit. Do you follow, or not?*

### 講評ポイント / Debrief points

| 論点 | 押さえるべきこと |
|---|---|
| 犯罪か、気になることか | 会社備品を従業員が持つこと自体は犯罪ではない。**権利の所在が不明確**。「明白性」の要件を満たしにくい |
| 私人か補助者か | ここは**補助者**の場面。確認の依頼・記録・報告はできるが、**強制はできない** |
| 追うか | **追わない判断も正解**。追跡は有形力に発展しやすく、People と Reputation を同時に危険にさらす |
| 報告 | 最重要。**時刻・品目・型番・会話内容**を事実として記録。評価は分けて書く |
| 結論 | **警備が結論を出さない。** 人事・法務へ渡すところまでが役割 |

**誘導する失敗** 「取り上げようとした」「出口で立ちふさがった」→ ここから2限の有形力の議論に戻す。

# TTX ② 巡回中、この場面に出会ったら ＜第4時限＞
# You Encounter This on Patrol — Period 4

**進め方** 6場面から班で3つ選ぶ → 4つの問いに回答 → 発表。
*Each group picks three of six scenes, answers all four questions, then presents.*

| # | 場面 / Scene | 主リスク | 見落としやすい点 |
|---|---|---|---|
| A | 無人の席にIDカードが置かれている | Asset（情報） | 拾って預かるのか、その場に残して報告か。**触れた記録を残す** |
| B | ホワイトボードに案件名と金額が残っている | Asset（情報）→ Reputation | 消してよいのか。**消す前に記録**が要る場合がある |
| C | 非常口の前に段ボールが3箱 | People | 避難障害。**その場で除去してよい**数少ない例 |
| D | サーバ室の扉が半開き | Asset（情報） | 中に人がいる可能性。**単独で入らない** |
| E | バッジ未着用の人物が執務フロアを歩行 | People / Asset | 従業員かもしれない。**断定しない声かけ**（5限に接続） |
| F | 外周フェンスの破損 | Asset（物的） | いつからか分からない。**写真と時刻**が価値をもつ |

### 4つの問い / The four questions
1. **何に注意するか** ― People / Asset / Reputation のどれか
2. **どこを見るか** ― ほかに確認すべき点
3. **どう巡回するか** ― 次の巡回で何を変えるか
4. **どう報告するか** ― 報告するか、誰に、何を（事実と評価を分けて）

### 講評ポイント
- リスクを **People / Asset / Reputation で言い分けられたか**
- 「その場の処置」と「報告」を**分けて**考えられたか
- ③まで踏み込めた班は少ない。**巡回設計の変更**に届いたかを褒める
- 報告文で**事実と評価が混ざっていないか**

# TTX ③ この台詞のうち、どれを選ぶか ＜第5時限＞
# Which of These Would You Say? — Period 5

**状況** 来訪者が「役員に呼ばれている、急いでいる」と述べ、入館手続きを拒んでいる。声はやや大きく、周囲の来訪者が振り返っている。

**Situation** A visitor claims an executive is expecting them and refuses to sign in. Their voice is raised; other visitors are looking.

### 提示する台詞 / The lines on offer

| | 台詞 | 評価 |
|---|---|---|
| **A** | 「規則ですので通せません」 | ✕ 拒否のみ。逃げ道がない。相手を追い詰める |
| **B** | 「お急ぎのところ恐れ入ります。すぐ確認いたしますので、こちらでお待ちいただけますか」 | ○ 承認＋手続きへの誘導＋待つ場所の提示 |
| **C** | 「落ち着いてください」 | ✕ 相手の状態を否定している。ほぼ確実に悪化する |
| **D** | 「どちらの役員でしょうか。お名前を伺えれば、こちらからお繋ぎします」 | ◎ 手続きに戻しつつ、**相手に協力の余地**を与える |

**最良は B → D の順**。Bで受け止め、Dで具体化する。

**追加付与 / Inject** 相手が「もういい」と言って、ゲートに向かって歩き出した。
*They say "forget it" and start walking toward the gate.*

### 講評ポイント
- 選んだ台詞は「拒否」ではなく**手続きへの誘導**になっているか
- **有形力**（進路に立つ、腕に触れる）に頼っていないか
- **逃げ道（面子）**を残したか／**選択肢**を示したか
- インジェクト後：**追わない。応援と通報に切り替える**。ゲートは物理的に止めない
- 退き際の基準を自分の言葉で言えるか

# TTX ④ 執務フロアで従業員が倒れている ＜第9時限＞
# An Employee Is Down on the Office Floor — Period 9

**状況** 17時40分、執務フロアで従業員1名が倒れている。近くに割れたガラスと、開いたままのキャビネット。周囲に3名の従業員がいるが、誰も通報していない。

**Situation** 17:40. An employee is down. Nearby: broken glass and an open cabinet. Three colleagues are present; nobody has called.

**追加付与 / Inject** 別の従業員が「早く片付けよう」と、割れたガラスを拾い始めた。
*Another employee starts picking up the broken glass.*

### 講評ポイント

| 論点 | 押さえるべきこと |
|---|---|
| 最初の30秒 | ①周囲の安全 ②反応の確認 ③**人を指名して**119番と応援を依頼（「誰か」では動かない） |
| 110か119か | **まず119**。人命が先。事件性は後から判断できるが、命は戻らない |
| 両方か | ガラスとキャビネットは事件性を示唆する。**119の後に110**、または社内から並行して |
| 現場保存 | **救護のためなら動かしてよい**。それ以外は触らない。範囲は広めに |
| インジェクト | **止める。**「そのままにしてください」と理由を添えて。片付けは善意なので、責めない言い方で |
| エスカレーション | 一次＝警備責任者へ即時。人身事故なので**三次（経営層・広報・法務）まで想定**に入る |

**評価の焦点** 通報の速さ、指名の有無、そして「片付けようとした人」への声かけの質。

# TTX ⑤ 総合演習 ＜第10時限＞
# Integrated Exercise — Period 10

**状況** 18時40分、受信機が3階東区画で発報。ほぼ同時刻、入退室ログに「退職者に返却済みのはずのカード」による3階の解錠記録。防火戸が閉鎖した。

**Situation** 18:40. Fire panel activation, third-floor east zone. At almost the same moment, the access log records a third-floor unlock by a card that should have been returned by a leaver. Fire doors have closed.

**追加付与 / Inject** 3階の従業員から「煙は見えない」と無線が入った。判断を変えるか。
*An employee radios: "no smoke visible." Does that change your decision?*

### 講評ポイント

| 論点 | 押さえるべきこと |
|---|---|
| 最初の60秒 | 地区表示を読む → 現場確認に向かう → **一報を入れてから動く**（動いてからでは遅い） |
| 通報 | **発報＝火災ではない**。現場確認前に119するかは社内基準による。**確認は単独で行かない** |
| インジェクト | 「煙が見えない」は**火災否定の根拠にならない**。感知器の位置と煙の性質が違う。**判断を変えない** |
| ログ・画像 | 退職者カードの解錠記録は**保全対象**。上書き前に依頼する。これに気づけた班を高く評価 |
| 現場保存 | 火災対応と証拠保全が競合する。**人命 → 消火 → 保全**の順を言えるか |
| 統合 | 1限（優先順位）2限（権限・個人情報）4限（巡回の視点）5限（対人）9限（通報・保存）が全て出る |

**この演習の狙い** 単一原因に見えて**2つの事象が重なっている**こと。片方（火災）に気を取られ、もう片方（不正解錠）を落とす班が必ず出る。そこが最大の学習点。

## AAR ― 演習後の振り返り（第10時限）
## After Action Review

**原則：犯人探しをしない。** / One rule: no blame.

1. 何が起きるはずだったか / What was supposed to happen?
2. 実際には何が起きたか / What actually happened?
3. なぜ差が生まれたか / Why was there a difference?
4. 次に何を変えるか / What will we do differently?

**締め** 各自が「明日から変える行動」を1つ、声に出して宣言する。
*Each participant states aloud one thing they will change from tomorrow.*
