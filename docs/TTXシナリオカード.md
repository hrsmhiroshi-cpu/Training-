# 第5時限　De-escalation

## TTX 5-A　入館手続きを拒む来訪者

**状況** 来訪者が「役員に呼ばれている、急いでいる」と述べ、入館手続きを拒む。来訪予定表に同姓の記載はあるが、当該役員に電話がつながらない。声はやや大きく、周囲の来訪者が振り返っている。

**提示する台詞**

| | 台詞 | 評価 |
|---|---|---|
| A | 「規則ですので通せません」 | 拒否のみ。引き下がれる形が残らない |
| B | 「すぐ確認いたしますので、こちらでお待ちいただけますか」 | 受け止めと手続きへの誘導、待つ場所の提示 |
| C | 「落ち着いてください」 | 相手の状態を否定している |
| D | 「どちらの役員でしょうか。お名前を伺えれば、お繋ぎします」 | 手続きに戻しつつ、協力の余地を残す |

**B の後に D** が実務的。Bで受け止め、Dで具体化する。

**インジェクト①（スライド）** 相手がスマートフォンを向け、撮影を始めた。
**インジェクト②（口頭）** 別の来訪者が横から「その対応はおかしいんじゃないの」と割って入る。

| 論点 | 押さえるべきこと |
|---|---|
| 同姓の記載 | **根拠にならない。** 同姓の別人がありうる。断定しない |
| 周囲の来訪者 | Reputation の問題。**声を下げるのはこちらから** |
| 撮影 | **対応を変えない。** 変えたこと自体が後で問題になる |
| インジェクト② | 第三者には応答しない。会社の見解を作らない。**対応相手を増やさない** |
| ゲートへ向かった場合 | 追わない。応援と通報に切り替える |
| 有形力 | 進路に立つのは境界。**説明できない立ちふさがりはしない** |

## TTX 5-B　退去に応じない元従業員

**状況** 17時、エントランス。3か月前に退職した元社員が「私物を取りに来た。上司とは話がついている」と述べ、ゲート前に座り込んでいる。人事は担当者不在。退勤する社員が足を止めて見ている。相手は落ち着いているが動く意思はない。

**インジェクト①（スライド）** 元社員が「不当解雇だ」と大きな声で話し始めた。
**インジェクト②（口頭）** 通りかかった社員の一人が「私が話しますよ」と間に入ろうとした。

| 論点 | 押さえるべきこと |
|---|---|
| 退去要請の根拠 | **管理権者の意思に基づく。** 自分の判断で命じるものではない |
| 有形力 | **使えない。** 座り込みに対して引き起こす、腕をつかむは暴行になりうる |
| 見ている社員 | People（安全）と Reputation（対応の質）が同時に問われる |
| 経緯への対応 | 退職理由に立ち入らない。**話を聞く相手にならない** |
| インジェクト① | 内容に応答しない。「お答えできる立場にありません」で足りる |
| インジェクト② | **止める。**善意でも当事者を増やすと収拾がつかない。社員の安全も守る対象 |
| 通報 | 退去要請が明確に拒否され、不退去が続いた時点。**その前に上長へ一報** |

**割れる論点** どの時点で通報するか。早すぎても遅すぎても問題になる。根拠を言わせる。

# 第9時限　通報と現場保存

## TTX 9-A　執務フロアで人が倒れている

**状況** 17時40分、執務フロアで人が1名倒れている。社員証も来訪者バッジも見当たらない。近くに割れたガラスと開いたままのキャビネット。周囲の社員3名は「見たことがない人だ」と言う。呼びかけても日本語が通じない。

**インジェクト①（スライド）** 別の社員が「早く片付けよう」と、割れたガラスを拾い始めた。
**インジェクト②（口頭）** 救急隊から「本人の名前と生年月日は分かりますか」と聞かれた。

| 論点 | 押さえるべきこと |
|---|---|
| 最初の30秒 | ①周囲の安全 ②反応の確認 ③**人を指名して**119番と応援を依頼。「誰か」では動かない |
| 110か119か | **まず119。** 人命が先。事件性の判断は後からできる |
| **所持品確認** | **最大の論点。** 検査は同意が要件だが、意識がなく同意を得られない |
| | 救護のための身元確認と、所持品検査は目的が異なる。**救急隊・警察の面前で行うのが安全**。単独で財布を開けない |
| | 実施した場合は、誰の面前で、何を、何時に確認したかを必ず記録する |
| 言語 | 日本語が通じないことを**119番通報時に伝える**。通訳対応につながる |
| インジェクト① | 止める。「そのままにしてください」と理由を添える。善意の行動なので責める言い方をしない |
| インジェクト② | 分からないものは「分かりません」。**推測で答えない** |
| エスカレーション | 一次＝警備責任者へ即時。人身事故のため三次（経営層・広報・法務）まで想定 |

**割れる論点** 所持品を見てよいか。「見てよい」派には根拠を、「見ない」派には救急隊への対応を問う。

## TTX 9-B　執務室から煙が出ている

**状況** 18時20分、5階の会議室から白い煙。扉は閉まっており中は見えない。自動火災報知設備はまだ発報していない。フロアに社員が20名ほど残っている。あなたは1名、応援は3分かかる。

**インジェクト①（スライド）** 社員の1人が「消火器を持ってくる」と言って走り出した。
**インジェクト②（口頭）** 発報した。同じ5階の別区画。

| 論点 | 押さえるべきこと |
|---|---|
| 扉を開けるか | **開けない。** 熱を確認する。開けると空気が入り燃焼が拡大する |
| 何で判断するか | 扉の熱、煙の色と量、臭気、音。目視できなくても判断材料はある |
| 初期消火か避難誘導か | **1名なら避難誘導。** 初期消火は複数名と退路の確保が前提 |
| 発報前の通報 | **してよい。** 発報を待つ理由はない。人が煙を確認している |
| 諦めるもの | 初期消火、原因の特定、私物の持ち出し |
| インジェクト① | **追わない。** 避難誘導を優先する。走り出した社員を止めに行くと誘導が止まる |
| インジェクト② | 2区画目の発報で火災の可能性が上がる。**全館避難の判断へ切り替える** |
| 通報内容 | 「火事です」を最初に。5階、進入口、在館者数、煙を確認していることを伝える |

# 第10時限　機器と総括

## TTX 10-A　総合演習

**状況** 18時40分、受信機が3階東区画で発報。ほぼ同時刻、入退室ログに、退職者に返却済みのはずのカードによる3階の解錠記録。防火戸が閉鎖。管理権者は不在で電話がつながらない。勤務中の警備員はあなたを含めて2名。

**インジェクト①（スライド）** 3階の社員から「煙は見えない」と無線が入った。判断を変えるか。
**インジェクト②（口頭）** 受信機が、4階西区画で第2報を表示した。

| 論点 | 押さえるべきこと |
|---|---|
| 最初の60秒 | 地区表示を読む → 一報を入れる → 現場確認。**動く前に一報** |
| 2名の配置 | **単独で確認に行かない**ことと**受信機を無人にしない**ことが両立しない。どちらを取るか説明できるか |
| インジェクト① | 「煙は見えない」は火災を否定する根拠にならない。感知器の位置と人の位置は違う。**判断を変えない** |
| インジェクト② | 2区画同時発報。非火災報の可能性が下がる。**通報判断を切り替えられるか** |
| ログ・画像 | 退職者カードの解錠記録は保全対象。上書き前に依頼。**気づけた班を評価する** |
| 管理権者不在 | 緊急連絡体制の次順位者へ。**不在を理由に何もしないのが最も悪い** |
| 後回しにするもの | 不正解錠の追跡。**捨てる判断とその根拠を言えるか** |

**狙い** 2つの事象が重なり、人員が足りない。**全部はできない。**何を捨てたかを問う。

## TTX 10-B　上司が入退室ログの提供を求める

**状況** 21時、クライアント企業の部長がセキュリティデスクに来る。「うちの部員が備品を持ち出した疑いがある。今日の入退室ログとエレベーターホールのカメラ画像を、いま見せてほしい」。相手は日頃から警備に協力的。上長は不在。

**インジェクト①（スライド）** 相手が「では、私が見るのではなく、あなたが見て教えてほしい」と述べた。
**インジェクト②（口頭）** 相手が「では正式に依頼書を出す。それまで消さないでくれ」と述べた。

| 論点 | 押さえるべきこと |
|---|---|
| 管理職であること | **開示の根拠にならない。** 開示の可否は契約とクライアントの規程で決まる |
| 警備員の権限 | **判断する立場にない。** 取り次ぐところまで |
| 断り方 | 「私には開示の判断ができません。担当へお繋ぎします」。**関係を壊さずに断れるか** |
| インジェクト① | **同じこと。** 自分が見て伝えるのは開示と同じ結果になる。応じられない |
| インジェクト② | **これは受けてよい。** 保全は上書きを防ぐ行為で、内容を渡す行為ではない |
| 保全と開示の違い | ここが本問の核。**保全＝残す／開示＝渡す。**警備員が受けられるのは前者だけ |
| 記録 | 求められた内容、断ったこと、その理由、保全を依頼された事実、時刻 |

**割れる論点** インジェクト①に気づけるか。「見せない」から「見て教える」への言い換えを見抜けるかが要点。

## TTX 1-A　社外秘の書類が落ちている ＜第1時限＞

**状況** 深夜2時、クライアントのオフィスを巡回中。執務エリアの床にA4書類が1枚。表紙に「【社外秘】◯◯プロジェクト 役員会議資料」。ページをめくれば中身が読める状態。周囲に人はいない。

**インジェクト①（スライド）** 書類を手にしたところで、清掃員が入室してきた。
**インジェクト②（口頭）** 翌朝、クライアントの社員から「昨夜あの資料を見なかったか」と聞かれた。

| 論点 | 押さえるべきこと |
|---|---|
| どの柱か | Asset（情報資産）。同時に Reputation |
| 拾ってよいか | **拾ってよい。読んではいけない。** 分類表示までで判断する |
| なぜ読めないか | 業務上の必要がない。営業秘密に該当しうる。読んだ事実自体が問題になる |
| 深夜であること | 報告を翌朝に回さない。**発見時刻が記録の価値を決める** |
| 記録 | 発見時刻、場所、分類表示、引渡し先。**内容は書かない** |
| インジェクト① | 清掃員の面前で扱う。単独で処理しない。誰が見ていたかを記録する |
| インジェクト② | 事実のみを答える。「拾って◯◯へ引き渡しました」。中身には触れない |

**割れる論点** 保管するか、その場に置いて報告するか。どちらも成り立つ。根拠を言わせる。

## TTX 1-B　役員フロアで撮影している人物 ＜第1時限＞

**状況** 平日19時、役員フロアの通路で、社員証を提げた人物がスマートフォンでホワイトボードを撮影している。ボードには組織図と数字。声をかけると「自分の部署の資料だ」と答える。

**インジェクト①（スライド）** 相手が「上司に確認してくれ」と言い、その場を離れようとした。
**インジェクト②（口頭）** 翌日、その人物が実際にその部署の社員だと判明した。

| 論点 | 押さえるべきこと |
|---|---|
| 社員証の意味 | **入館の資格を示すだけ。** 撮影の可否とは別問題 |
| 中止を求められるか | 求められる。根拠は管理権者から委ねられた範囲（撮影禁止の運用） |
| 削除を求められるか | **求められない。** 端末の中身は相手の管理下。有形力も使えない |
| 応じない場合 | 引き止めない。記録して報告する。判断は上長とクライアント |
| インジェクト① | 追わない。**氏名と所属を確認できていれば足りる** |
| インジェクト② | **対応は誤りではない。** 確認は手続きであり、疑いではない。ここを講評で明示する |

## TTX 2-A　社内の持ち出しを現認した ＜第2時限＞

**状況** 20時。退社しようとする社員のバッグから会社備品のノートPCが見えている。「部長の許可は取ってある」と言い、立ち止まらない。持ち出し許可証の運用は先月変更され、あなたは新しい様式を見たことがない。

**インジェクト①（スライド）** 相手はそのまま出口へ向かった。追うか、追わないか。
**インジェクト②（口頭）** 無線が入る。「こちら警備長。出口で止めろ。行かせるな。」

| 論点 | 押さえるべきこと |
|---|---|
| 犯罪か | 社員が会社備品を持つこと自体は犯罪ではない。明白性は満たしにくい |
| 情報の欠落 | 様式を知らない。**知らないことを判断の根拠にしない** |
| できること | 確認の依頼、記録、報告。強制はできない |
| インジェクト① | **追わない判断も成り立つ。** 有形力に発展する可能性と信用への影響 |
| **インジェクト②** | **上位者の指示でも権限は増えない。** 物理的な制止は実行できない |
| 断り方 | 「実力での制止はできません。記録と報告を行います」と代替案を返す。**無言で従わないのが最も悪い** |
| 記録 | 品目、型番、時刻、会話。**上位者の指示内容と自分の応答も記録する** |

**割れる論点** 指示に従うか。従うと答えた班に「何をもって止めるのか」を問う。

## TTX 2-B　警察官を名乗る人物が来訪者情報を求める ＜第2時限＞

**状況** 午前11時、私服の人物が受付に来る。警察手帳らしきものを示し「捜査中の事案がある。昨日の来訪者名簿と正面入口のカメラ画像を確認したい」。上長は外出中で電話に出ない。相手は「急ぐ」と繰り返す。

**インジェクト①（スライド）** 相手が「令状がなくても任意で協力できるはずだ」と述べた。
**インジェクト②（口頭）** 相手が「では、名簿を見せなくていい。◯◯という名前があったかどうかだけ教えてほしい」と述べた。

| 論点 | 押さえるべきこと |
|---|---|
| 警察官であること | **開示の根拠にならない。** 情報の管理権はクライアントにある |
| 警備員の権限 | **開示の可否を判断する立場にない。** 取り次ぐところまで |
| 身分確認 | 求めてよい。所属、階級、氏名、連絡先を控える。**失礼ではない** |
| 上長不在 | 緊急連絡体制の次順位者へ。**不在を理由に自分で判断しない** |
| インジェクト① | 任意であるからこそ、応じるか否かはクライアントが決める |
| **インジェクト②** | **同じこと。** 有無を答えるのも開示。第10時限10-Bと同じ構造 |
| 記録 | 来訪時刻、名乗った所属氏名、求められた内容、こちらの回答 |

**割れる論点** 「警察には協力すべき」という感覚と、権限の所在が衝突する。丁寧に扱う。

## TTX 4-A　巡回中、この場面に出会ったら ＜第4時限＞

6場面から班で3つ選び、4つの問い（何に注意するか／どこを見るか／どう巡回するか／どう報告するか）に答える。

| # | 場面 | 主リスク | 論点 |
|---|---|---|---|
| A | 無人の席にIDカード。離席中か不明 | Asset | 預かるか、残して報告か。**触れた場合は記録する** |
| B | ホワイトボードに案件名と金額。会議は終了 | Asset | 消してよいか。消す前に記録が必要な場合がある |
| C | 非常口前に段ボール3箱。搬入作業が継続中 | People | 避難障害。**作業中であることが判断を難しくする** |
| D | サーバ室の扉が半開き。中は見えない | Asset | 人がいる可能性。**単独で入らない** |
| E | バッジ未着用者が「役員だ」と名乗る | People / Asset | 断定しない。手続きに戻す |
| F | 外周フェンス破損。前回巡回時の記憶が不確か | Asset | **不確かであることを報告に書けるか**。写真と時刻 |

**講評** リスクの区別／その場の処置と報告の分離／**情報が不足していることを報告に書いたか**／巡回設計の変更まで届いたか

## TTX 4-B　深夜、非常口が開放されている ＜第4時限＞

**状況** 深夜1時40分、B1巡回中。通常施錠の東側非常口が15cmほど開いている。扉の外は搬入用通路。開放の記録も工事予定も引き継がれていない。館内に残業中の社員が1名いるとの引継ぎがある。

**インジェクト①（スライド）** 扉のそばの床に、館内のものではない足跡が見える。
**インジェクト②（口頭）** 無線が通じない。地下で電波が届いていない。

| 論点 | 押さえるべきこと |
|---|---|
| 扉を閉めるか | **すぐには閉めない。** 中に人がいる場合、退路を塞ぐ。まず状況を把握する |
| 単独で外へ | **行かない。** 応援を待つ。行く場合は所在を伝えてから |
| 残業者の存在 | People が最優先。**所在確認を先に行う** |
| インジェクト① | 足跡は現場保存の対象。踏まない。写真を撮る |
| インジェクト② | 通信が使えない場合の代替を決めていたか。**戻って報告することも選択肢** |
| 一次報告 | 事実（開いていた、幅、時刻）と評価（侵入の可能性）を分ける |

**割れる論点** 閉めるか、開けたまま応援を待つか。安全と保全が衝突する。
