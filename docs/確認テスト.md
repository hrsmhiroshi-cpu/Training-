# 解答と解説（講師用） / Answer Key — Facilitator Copy

| 問 | 解答の要点 | 対応するコマ |
|---|---|---|
| **1** | **私人。制服により権限は加わらない。** ／ 警察官にあって警備員にない権限：職務質問、保護、避難等の措置、犯罪の予防及び制止、立入、武器の使用、逮捕状による逮捕・取り調べ（いずれか1つ） | 第5限 前提 |
| **2** | **有形力を使わずに緊張を下げ、その場を安全に終えること。** 相手に勝つことではない | 第5限 |
| **3** | 逃げ道がないと、相手は引き下がれず**対立を続けるほかなくなる**ため | 第5限 |
| **4** | 兆候：声が大きくなり続ける／同じ言葉を繰り返す／距離を詰める／持ち物を握りしめる／視線を外さない（2つ）。**行動は順に、離脱する → 応援を要請する → 通報する** | 第5限 |
| **5** | **管理権者の意思**。警備員が自分の判断で命じるものではない | 第5限・TTX 5-B |
| **6** | 問題点：**見ていない「侵入」を断定している**（事実と評価の混同）。報告例：「20時15分、B1東側非常口が15cmほど開いていた。施錠されているはずの扉で、付近に人影はない。侵入の可能性があると思われる」 | 第9限　**重点問題** |
| **7** | **種別。「火事です」か「救急です」。** 場所より先に言う | 第9限 |
| **8** | **人命（救助・救護）のため。** それ以外では動かさない。動かした場合は何を・どこから・どこへ・誰が・何時にを記録 | 第9限 |
| **9** | **地区表示**（どこが鳴っているか）。「火事です」とは**言わない**。発報は火災の確定ではない | 第10限　**重点問題** |
| **10** | **保全＝上書きを防いで残す／開示＝内容を渡す。** 警備員が受けられるのは**保全のみ** | 第10限・TTX 10-B |
