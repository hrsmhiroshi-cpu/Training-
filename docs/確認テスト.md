# 解答と解説（講師用） / Answer Key — Facilitator Copy

| 問 | 解答の要点 | 解説で必ず触れる点 |
|---|---|---|
| **1** | この法律により**特別に権限を与えられているものではない**こと。他人の権利・自由を侵害せず、正当な活動に干渉しない | 「制服＝権限」ではない。立場は**私人**。ここが本日の全ての土台 |
| **2** | **People / Asset / Reputation**。情報は **Asset** に含まれる | 物的資産と情報資産の両方が Asset。書類1枚も Asset |
| **3** | ①**誰でもできること**（現行犯逮捕・正当防衛・緊急避難）②**管理権者から委ねられたこと**（入館可否・退去要請・立入制限・記録） | この2つの外側に権限はない。迷ったら「どちらに当たるか」を問う |
| **4** | **直ちに警察官等へ引き渡す**（刑訴法214条）。してはならない例：事務所での事情聴取、サインの要求、私物の確認 | **取り調べる権限はない**。留め置けば逮捕監禁罪になりうる |
| **5** | **相手の任意の同意がある場合のみ**。権限規定はない | 「断れない状況での同意」は同意ではない。依頼形で言う |
| **6** | 問題点：**見ていないことを断定している**（事実と評価の混同）。書き直し例：「20時15分、B1東側非常口が15cmほど開いていた。侵入者の可能性があると思われる」 | 事実が先、評価は明示して後。**この1問が9限の核心** |
| **7** | **「火事です」か「救急です」** ― 種別を最初に言う | 種別で出動する部隊が変わる。場所より先 |
| **8** | **人命（救助・救護）のため**。それ以外の理由では動かさない | やむを得ず動かしたら、何を・どこから・どこへ・誰が・何時にを記録 |
| **9** | **地区表示**（どこが鳴っているか）。「火事です」とは**言ってはいけない**。発報＝火災ではない | 言い方の例：「3階東区画、発報。現場確認に向かいます」 |
| **10** | 逃げ道がないと、相手は**引き下がれず戦うしかなくなる**から。目的は勝つことではなく収めること | 選択肢を2つ示すと、相手は選べる＝戦わなくてよくなる |
