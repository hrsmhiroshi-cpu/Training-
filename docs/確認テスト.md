# 解答と解説（講師用） / Answer Key — Facilitator Copy

| 問 | 解答の要点 | 解説で触れる点 |
|---|---|---|
| **1** | この法律により**特別に権限を与えられているものではない**こと。他人の権利・自由を侵害せず、正当な活動に干渉しない。／ 警察官にあって警備員にない権限：職務質問、保護、避難等の措置、犯罪の予防及び制止、立入、武器の使用、逮捕状による逮捕・取り調べ（いずれか1つ） | 制服により権限は加わらない。立場は私人。警備業法16条により服装も区別が求められる |
| **2** | **People / Asset / Reputation**。情報は **Asset** に含まれる | 物的資産と情報資産の両方が Asset。書類1枚も Asset |
| **3** | ①**誰でもできること**（現行犯逮捕・正当防衛・緊急避難）②**管理権者から委ねられたこと**（入館可否・退去要請・立入制限・記録） | この2つの外に権限はない。迷ったらどちらに当たるかを問う |
| **4** | **直ちに警察官等へ引き渡す**（刑訴法214条）。してはならない例：事務所での聴取、サインの要求、私物の確認 | 取り調べる権限はない。留め置けば逮捕監禁罪に当たりうる |
| **5** | **相手の任意の同意がある場合に限る**。権限規定はない | 断ることができない状況での同意は同意にならない。依頼の形で伝える |
| **6** | 問題点：**見ていないことを断定している**（事実と評価の混同）。書き直し例：「20時15分、B1東側非常口が15cmほど開いていた。侵入者の可能性があると思われる」 | 事実が先、評価は明示して後。**重点問題** |
| **7** | **「火事です」か「救急です」** ― 種別を最初に伝える | 種別により出動する部隊が変わる。場所より先 |
| **8** | **人命（救助・救護）のため**。それ以外の理由では動かさない | 動かした場合は、何を・どこから・どこへ・誰が・何時にを記録する |
| **9** | **地区表示**（どこが発報しているか）。「火事です」とは**言わない**。発報は火災の確定ではない | 言い方の例：「3階東区画、発報。現場確認に向かいます」。**重点問題** |
| **10** | 引き下がる形がないと、相手が対立を続けるほかなくなるため。目的は安全に終えること | 選択肢を2つ示す。追い詰めない |
