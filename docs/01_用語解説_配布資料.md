# 用語の確認 ― 施設警備 現任教育 配布資料

**実施日**：2026年8月11日　**対象**：施設警備業務（警備業法第2条第1項第1号）従事者

**この資料の使い方**
本日私が担当する **1・2・4・5・9・10限** で共通して使う用語をまとめています。
経験者の皆さんこそ「**よくある誤り**」の欄を読んでください。本日のTTX（図上訓練）はそこを突いてきます。

---

## 第1部　自分の立ち位置 ＜1限：基本原則＞

| 用語 | 意味 |
|---|---|
| **警備業務（1号業務）** | 事務所・住宅・興行場・駐車場・遊園地等における盗難等の事故の発生を警戒し、防止する業務 |
| **警備員** | 警備業者の使用人その他の従業者で、警備業務に従事する者 |
| **管理権者** | その施設を管理する権限をもつ者。**警備員は管理権者ではなく、その補助者** |
| **警備業務実施の基本原則** | 警備業法第15条（下記） |

### ■ 本日の背骨 ― 警備業法 第15条

> 警備業者及び警備員は、警備業務を行うに当たっては、**この法律により特別に権限を与えられているものでないこと**に留意するとともに、他人の権利及び自由を侵害し、又は個人若しくは団体の正当な活動に干渉してはならない。

**読み替え**：制服を着ていても、法的な立場は**通行人と同じ「私人」**です。
警備員だからできることは一つもありません。できるのは次の2つだけ。

1. **誰でもできること**（例：現行犯逮捕、正当防衛）
2. **管理権者から委ねられた範囲のこと**（例：入館の可否、退去の要請）

**この2つの区別が、本日のTTXすべての判断軸になります。**

---

## 第2部　権限と限界 ― 越えた瞬間に何になるか ＜2限：法令＞

「やっていい／悪い」ではなく、**越えると自分が何に問われるか**で覚えてください。

| 用語 | 根拠 | できること | 越えると | よくある誤り |
|---|---|---|---|---|
| **現行犯逮捕** | 刑訴法213条 | 現行犯人は**何人でも**逮捕状なしに逮捕できる | 逮捕監禁罪 | 「怪しいから」で拘束。**犯罪の明白性**が要る。疑いだけでは足りない |
| **準現行犯** | 刑訴法212条2項 | 犯行直後で、贓物所持・返り血等の要件を満たす者 | 同上 | 時間が空いてから追って捕まえる。直後性が失われると成立しない |
| **逮捕後の措置** | 刑訴法214条 | **直ちに**警察官等へ引き渡す | 逮捕監禁罪 | 事務所に留め置いて自社で聞き取る。**取り調べる権限はない** |
| **所持品検査** | 権限規定なし | **相手の任意の同意がある場合のみ** | 強要罪等 | 「規則ですから」とカバンを開けさせる。**断れない状況での同意は同意ではない** |
| **正当防衛** | 刑法36条 | 急迫不正の侵害に対する、やむを得ない防衛 | 過剰防衛（36条2項） | 相手が倒れた後も続ける。**侵害が終われば正当防衛も終わる** |
| **緊急避難** | 刑法37条 | 現在の危難を避けるため、生じた害が避けようとした害を超えない範囲 | 過剰避難 | 被害の釣り合いを考えずに他人の物を壊す |
| **自救行為** | 明文なし | **原則として認められない** | 各種犯罪 | 盗まれた物を実力で取り返す |
| **退去要求／不退去** | 刑法130条後段 | 管理権者（またはその委任を受けた者）が退去を求められる | ― | **自分の判断で**退去を命じる。管理権者の意思に基づくことが前提 |
| **建造物侵入** | 刑法130条前段 | 管理権者の意思に反する立入り | ― | 「入館証がない＝即侵入罪」ではない。基準は管理権者の意思 |
| **有形力の行使** | ― | 正当防衛・現行犯逮捕に伴う必要最小限のみ | 暴行罪・傷害罪 | 肩をつかむ、腕をひねる、進路に立ちふさがる。**説得は有形力ではない** |

### ■ 迷ったら、この3つを順に自問する

1. **目の前で起きているのは「犯罪」か、「気になること」か？**
2. **私はいま「私人」として動くのか、「管理権者の補助者」として動くのか？**
3. **その手段は、目的に対して最小限か？**

## 第3部　巡回と機器の用語 ＜4限：巡回／10限：機器＞

| 用語 | 意味・押さえどころ |
|---|---|
| **定時巡回／不定時巡回** | 定時＝時刻を定めて実施。**不定時＝時刻をずらす**。定時のみだと「警備員がいない時間」を読まれる |
| **巡回経路** | 巡回する順路。**毎回同じ順路は経路を読まれる**ため、逆順・分割等で変化をつける |
| **立寄点（チェックポイント）** | 必ず立ち寄り確認する地点。確認したことを記録に残せる地点であること |
| **警戒点** | 事故が起きやすい／被害が大きい重要箇所（受電設備、金庫室、サーバ室、危険物、非常口） |
| **死角** | 目視できない範囲。**巡回設計とは死角をどう潰すかの設計** |
| **巡回記録** | 実施の証跡。「異常なし」も記録する。**記録のない巡回は、していないのと同じ** |
| **警報装置** | 異常を検知して知らせる機器の総称 |
| **受信機** | 火災等の発報を受け、**発報場所（地区）を表示**する装置。まず見るのは「どこが鳴っているか」 |
| **発報／誤報／非火災報** | 発報＝作動。**発報を受けた時点では、まだ火災と決まっていない**。現場確認までは断定しない |
| **連動** | 発報に伴い他設備が自動作動すること（防火戸、防排煙、非常放送、エレベーター管制） |
| **無線交話要領** | 簡潔・明瞭・復唱。**呼び出し→応答→用件→復唱→終話** |

## 第4部　通報と現場保存の用語 ＜9限：応急の措置＞

### ■ 事実と評価を分ける（最重要）

| | 例 |
|---|---|
| **事実**（見た・聞いた） | 「20時15分、B1東側非常口が15cmほど開いていた」 |
| **評価**（思った・推測） | 「侵入者がいるかもしれない」 |
| **NG（混ざっている）** | 「不審者が非常口から入りました」← **見ていないのに断定している** |

**事実を先に。評価は「〜と思われます」と明示して後に。**

### ■ 報告の3段階

| 段階 | タイミング | 内容 |
|---|---|---|
| **一次報告** | 覚知後ただちに | 何が・どこで・いま安全か。**完全でなくてよい。速さ優先** |
| **続報** | 状況が動くたび | 変化点のみ。「変化なし」も報告する |
| **確定報** | 事案終了後 | 経過・対応・引継事項 |

### ■ 通報で必ず言う事項

| | 110番 | 119番 |
|---|---|---|
| 冒頭 | 事件です | **火事です／救急です**（最初に種別） |
| 場所 | 住所＋**目標物**＋建物名・階・区画 | 同左（**進入口も**） |
| 状況 | 何が起きたか、負傷の有無 | 症状・負傷者数・意識/呼吸の有無 |
| 相手 | 人相・着衣・逃走方向・車両 | ― |
| 自分 | 氏名・**折り返しの電話番号**・現在地 | 同左 |

**通報は「切られるまで切らない」。** 相手の質問に答え切ってから終話します。

### ■ 現場保存

| 原則 | 内容 |
|---|---|
| **人命最優先** | 救助・救護のためなら現場を変えてよい。**それ以外の理由で動かさない** |
| **変えたら記録** | やむを得ず動かした場合、**何を・どこから・どこへ・誰が・何時に**を記録 |
| **範囲を広めに** | 立入制限は「ここまでだろう」より一回り広く |
| **触らない・拾わない・片付けない** | 良かれと思った片付けが証拠を消す |
| **記録は早いほど正確** | 引き揚げてから思い出すのではなく、その場でメモ・写真 |
